# Showcase Thumbnails Folder

Drop your custom YouTube thumbnails into this folder to have them automatically display in the scrolling marquee wall on your website.

## Supported File Formats:
- `.jpg` / `.jpeg` (Recommended)
- `.png`
- `.webp`

*(The website automatically detects and supports `.jpg`, `.png`, and `.webp` formats)*

## Recommended Image Specs:
- **Aspect Ratio**: 16:9
- **Resolution**: 1280×720 or 1920×1080
- **Size**: Under 500 KB per image for fast loading
